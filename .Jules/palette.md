## 2026-08-14 - Accessible Booking Flows and Reusable Inputs
**Learning:** For multi-step wizard processes like appointment scheduling, standard visual-only indicators of progress and selection (e.g. highlighted time slots or date pickers) leave screen reader users completely disoriented. Proper accessibility requires pairing date inputs with explicit labels using React's `useId`, container grouping of optional choices via `role="group"` with a descriptive `aria-label`, and letting screen readers know which option is active using `aria-pressed`.
**Action:** When designing wizards or form systems, always generate dynamic unique IDs using the `useId` hook to pair labels and inputs, wrap multi-select grids or option lists in named accessibility groups, and statefully toggle `aria-pressed` or `aria-selected` attributes.

# Agent Instructions for Shie MakeOvers

## Project Overview
Shie MakeOvers is a modern nail salon booking platform built with Next.js, TypeScript, Tailwind CSS, and Prisma.

## Coding Standards
- Use functional components and React hooks.
- Use Tailwind CSS for styling.
- Ensure all components are responsive.
- Use Lucide React for icons.
- Follow the "elegant, minimalist, feminine" aesthetic.

## Database
- Use Prisma for database interactions.
- Schema is located in `prisma/schema.prisma`.

## Testing
- Ensure API routes work as expected.
- Verify UI responsiveness on mobile and desktop.
